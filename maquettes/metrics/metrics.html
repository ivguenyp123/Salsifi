🔁 Boucle d'apprentissage

Chaque exécution laisse une trace : réussite, correction humaine, 👍/👎. Ces signaux nourrissent les scores, font remonter les recettes à améliorer, et guident l'ai-maintainer dans le Studio — les bons prompts deviennent réutilisables ailleurs.
Usage→Signal 👍/👎→Score→À améliorer→Studio : nouvelle version↺
